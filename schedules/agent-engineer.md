# 智能体工程师训练营

面向需要以 AI 智能体方式开展研发、自动化与交付的成员，训练从工具使用到方法论自觉的能力。

## Task 1：熟悉量潮数据工程第二大脑

以新人视角通读数据工程领域第二大脑（quanttide-data 主仓库、资产图式章程、发布管理章程），记录「知识诅咒」视角下的困惑，并提出改进建议。达成：至少一条建议经 Issue 讨论达成共识后进入 PR。

来源：tasks/data-second-brain.md

## Task 2：共识链识别实验

验证「共识链」可以被大模型识别：复制真实讨论内容到网页版大模型，提取讨论者们依次形成的共识（含「悬而未决」类共识），检验还原度。达成：提交验证结果（还原的共识链条、识别遗漏案例、共识链建模想法），经 Issue 讨论进入 PR。

来源：tasks/connect-lab.md

## Task 3：文档工程章程升级

把使用《文档工程格式章程》的真实感受带回来，升级成「社区版」。达成：对照章程提出顺手/困惑/建议，讨论达成共识后更新章程文件。

来源：tasks/docs-bylaw.md

# 更新数据工程路线图

请根据整理好的意图和洞察，更新数据工程路线图（roadmap）。

## 路线图的定位

路线图是「未来的事件记忆」，它的主要功能是回答下一步要做什么——这也是给你自己和团队未来的工作清单。它经过分类和排期以后，就可以成为某个具体仓库的 ROADMAP 文件，方便进入正式的开发流程。

## 步骤

1. 阅读现有路线图：https://github.com/quanttide/quanttide-roadmap-of-data-engineering
2. 结合数据工程意图与洞察，更新路线图：
   - 意图：https://github.com/quanttide/quanttide-intention-of-data-engineering
   - 洞察：https://github.com/quanttide/quanttide-insight-of-data-engineering
3. 通过 Issue 和 PR 与团队沟通你的整理结果

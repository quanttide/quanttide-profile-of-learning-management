# 量潮科技学习管理档案

本目录为量潮科技（qttech）组织在 qtcloud-learn 平台上的学习管理文件夹，承载组织及其成员的学习档案。

## 组织信息

| 属性 | 值 |
|------|-----|
| 组织 ID | qttech |
| 组织名称 | 量潮科技 |
| 组织类型 | enterprise |
| 管理平台 | qtcloud-learn |

## 档案结构

遵循 [learning-profile 设计文档](https://github.com/quanttide/qtcloud-learn/blob/main/docs/dev-guide/learning-profile.md)，每位成员一个文件，用昵称命名，记录验收结果：

```
qttech/
├── README.md
├── iGuo.md
├── zhangsan.md
└── ...
```
